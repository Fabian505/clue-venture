# Feature: Gamification

- Für das Erreichen der Zwischenstationen muss der Benutzer eine hinterlegte Anzahl an Punkten erhalten.
- Für den Abschluss eines Abenteuers muss der Benutzer eine hinterlegte Anzahl an Punkten erhalten.
- Die durch einen Benutzer gesammelten Punkte sollen verwendet werden um auf dem Benutzerprofil angezeigt zu werden oder den Benutzer auf der globalen Rangliste einzuordnen.
- Der Benutzer erhält nicht die vollständigen Punkte wenn dieser für die Erreichung des nächsten Orts zu lange benötigt hat.

# Hinweise

- Erfassung maximal drei Hinweise.
- Ein Hinweis ist eine Beschreibung welche den Anwender zum nächsten Punkt führen soll.
- Der erste Hinweis ist immer frei und wird mit dem erreichen des Punkts angezeigt.
- Die maximal zwei verbleibenden Hinweise müssen mit Punkten erkauft werden.

# Rätsel

- Fragen mit Multiple-Choice-Antworten
- Eine richtig beantwortete Frage gibt Punkte.
- Pro 200 Meter Strecke vom aktuell erreichten Punkt zum nächsten Punkt bekommt der Anwender Rätsel zum lösen.
- Ein Rätsel kann der Anwender über eine Schaltfläche starten.
- An der Schaltfläche sollte sichtbar sein wie viele Rätsel der Anwender machen kann.
- Rätsel verfallen nicht.
