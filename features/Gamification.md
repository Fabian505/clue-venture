# Feature: Gamification

- Für das Erreichen der Zwischenstationen muss der Benutzer eine hinterlegte Anzahl an Punkten erhalten.
- Für den Abschluss eines Abenteuers muss der Benutzer eine hinterlegte Anzahl an Punkten erhalten.
- Die durch einen Benutzer gesammelten Punkte sollen verwendet werden um auf dem Benutzerprofil angezeigt zu werden oder den Benutzer auf der globalen Rangliste einzuordnen.
- Der Benutzer erhält nicht die vollständigen Punkte wenn dieser für die Erreichung des nächsten Orts zu lange benötigt hat.
